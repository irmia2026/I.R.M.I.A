# 情绪（linre-affect）

这个插件维护九维心绪状态（喜悦、低落、恼怒、焦虑、挂念、信任、得意、羞赧、好奇），按说话人信任权重加权吸收事件冲击，并随时间向基准线指数衰减。

## 什么时候用它

- 想让对话带有自然的当下心绪余温（如被调侃后的微恼带挂念、被关心后的信任感提升）。
- 想在长期相处中持久化保留心绪变化与心境轨迹。

## 分诊与边界保护

- 自动跳过无实质含义的短应答（如 `嗯`、`好的`、`ok`）与 `/斜杠指令`，以及带 `via` 标记的非直接唤醒。
- 依据 `ownerIds` 区分 `owner (1.0)`、`trusted (0.65)` 与 `external (0.25)`；非主人发出越界撩拨（`unwelcome_advance`）时触发边界保护，清零喜悦/挂念/信任并提升恼怒与焦虑。

## 数据与容错

- 状态持久化在 `<dataDir>/state.json`，重启后按经过时间自动衰减。
- 模型评价走 `light` 档并带双重超时保护（4000ms + 4250ms 硬超时），失败或未授权时 fail-open，不阻塞主对话。
